# Conteúdo do curso

Notas de referência dos temas da disciplina de Microeconomia que o MicroLab cobre, na
sequência em que são dados em aula, **até Estruturas de Mercado**.

## Por que estas notas existem

Os laboratórios precisam de uma fonte única sobre *o que* cada tema exige: quais conceitos
entram, qual a notação, o que o aluno já deve saber. Sem isso, cada lab inventa seu próprio
recorte e o conjunto deixa de acompanhar a aula.

**Estas notas são texto próprio**, escritas em termos genéricos de microeconomia — o mesmo
conteúdo que se encontra em qualquer manual introdutório. Não reproduzem os slides da
disciplina, que são material do professor e não são redistribuídos aqui.
